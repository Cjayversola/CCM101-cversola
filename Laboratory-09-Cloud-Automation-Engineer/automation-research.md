# Automation Research

## 1. Bash Script

A Bash script is a file that contains commands that can run automatically in a Linux system. It helps users perform repeated tasks faster without typing every command manually.

## 2. Shebang (#!/bin/bash)

The shebang is the first line of a Bash script. It tells the operating system to use Bash when running the script.

## 3. Variables

Variables are used to store information or values that a script can use. For example, `$BACKUP_DIR` stores the name or location of the directory where backup files will be saved.

## 4. Cron Job

A cron job is a scheduled task in Linux that runs commands or scripts at a specific time. It is useful in cloud operations because it can automatically perform tasks such as backups and system maintenance.
