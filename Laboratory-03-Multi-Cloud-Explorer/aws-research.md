# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers many cloud services for computing, storage, networking, databases, security, analytics, and artificial intelligence. AWS is widely used by startups, businesses, government organizations, and large enterprises.

## Global Infrastructure

AWS operates through geographic Regions and Availability Zones around the world. Each Region contains multiple isolated Availability Zones that can be used to build highly available applications. AWS currently lists 39 geographic Regions and 124 Availability Zones. 

## Cloud Management Console

The AWS Management Console is a web-based interface used to create, configure, monitor, and manage AWS resources. Users can access services such as EC2, S3, IAM, and VPC from the console.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can run applications and operating systems in the cloud.

### 2. Amazon S3

Amazon Simple Storage Service (S3) provides object storage for files, documents, backups, images, and other data.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create an isolated virtual network for their AWS resources.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls access to AWS resources by managing users, roles, permissions, and policies.

## Three Advantages

1. AWS provides a large selection of cloud services for different business and technical requirements.
2. Its global infrastructure allows applications to be deployed closer to users in different parts of the world.
3. AWS supports scalable infrastructure, allowing organizations to increase or decrease resources based on demand.

## Typical Enterprise Use Cases

AWS is commonly used for web and mobile applications, enterprise applications, backup and disaster recovery, data analytics, artificial intelligence, and large-scale e-commerce systems.
