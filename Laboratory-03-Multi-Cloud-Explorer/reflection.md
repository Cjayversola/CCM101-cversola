# Reflection

In this laboratory activity, I learned more about AWS, Microsoft Azure, and Google Cloud Platform. Before doing this activity, I knew that these platforms were used for cloud computing, but I did not have a clear idea about the different services they provide. After researching each platform, I understood that cloud providers offer many similar services, but they also have different strengths depending on what a company needs.

The cloud platform that impressed me the most was AWS. I chose AWS because it has a very wide range of services for computing, storage, networking, databases, security, and other cloud needs. While researching it, I noticed that AWS can be used by both small businesses and large organizations. However, I also learned that Azure and GCP are strong platforms and can be a better choice in certain situations.

AWS, Azure, and GCP have many similarities. All three provide virtual machines, storage, databases, networking, identity management, and other services. They also provide ways to scale applications, improve availability, and manage resources through cloud consoles. Even though the services have different names, many of them perform similar functions.

Business requirements are important when choosing a cloud platform. For example, a university that already uses Windows Server, Microsoft 365, and Active Directory may find Azure more convenient. An AI research company may prefer GCP because of its strong AI and machine learning services. This showed me that there is no single cloud provider that is always the best for every situation.

Acting as a Cloud Solutions Consultant taught me to look at the actual needs of the client before making a recommendation. I learned that factors such as budget, existing technology, performance, scalability, and business goals should be considered.

This activity also helped improve my GitHub Cloud Computing Portfolio. I practiced creating organized Markdown files, comparing cloud services, researching official documentation, and documenting my Linux environment. I also became more familiar with using GitHub to keep my laboratory activities organized. Overall, this activity gave me a better understanding of how cloud computing is used in real-world business situations.
