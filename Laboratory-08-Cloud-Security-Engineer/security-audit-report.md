# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users and applications only the permissions they need to perform their tasks. This helps protect cloud accounts and systems from unauthorized access and reduces possible security risks.

## 2. Attack Surface

The attack surface refers to all the possible points where an attacker can try to access or attack a virtual machine. Open ports, running services, and weak passwords can increase the attack surface.

## 3. Default Deny Policy

A Default Deny Policy means blocking all incoming network traffic unless it is specifically allowed. This is safer because only trusted and necessary connections can access the server, reducing the chance of unauthorized access.
