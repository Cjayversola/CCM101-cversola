# Mission 5: The Cloud Data Engineer

## Mission Overview

In this activity, I deployed a MinIO object storage server using Docker. I created a bucket named `client-photos` and accessed the MinIO web console to manage stored files.

## Objectives

- Understand the differences between block, file, and object storage.
- Deploy MinIO using Docker.
- Access the MinIO web console through port 9001.
- Create a bucket for storing photos.
- Document the deployment process using Markdown.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- MinIO
- GitHub
- Web Browser

## Skills Learned

I learned how to run a storage service using Docker, configure environment variables, access a web console through port forwarding, and organize data using an object storage bucket. I also practiced documenting my work using Markdown.
