# Cloud Provider Comparison

## Comparison of Core Infrastructure Services

| Infrastructure Component             | AWS        | Microsoft Azure                 | Google Cloud Platform |
| ------------------------------------ | ---------- | ------------------------------- | --------------------- |
| Compute                              | Amazon EC2 | Azure Virtual Machines          | Compute Engine        |
| Storage                              | Amazon S3  | Azure Storage                   | Cloud Storage         |
| Networking                           | Amazon VPC | Azure Virtual Network           | Google Cloud VPC      |
| Identity and Access Management (IAM) | AWS IAM    | Azure RBAC / Microsoft Entra ID | Google Cloud IAM      |

### Compute

Amazon EC2 provides scalable virtual computing capacity in AWS. Azure Virtual Machines provides on-demand and scalable virtual machines, while Google Compute Engine provides virtual machine instances for cloud workloads.

### Storage

Amazon S3 is an object storage service that stores data in buckets. Azure Storage provides several storage services including Blob Storage and managed disks, while Google Cloud Storage stores objects in buckets and provides scalable managed storage.

### Networking

Amazon VPC provides an isolated virtual network where AWS resources such as EC2 instances can operate. Azure provides virtual networking for its resources, while Google Cloud VPC provides networking for Compute Engine, GKE, and other cloud workloads.

### Identity and Access Management

AWS IAM controls who can authenticate and what permissions they have for AWS resources. Azure RBAC manages who can access Azure resources and what actions they can perform. Google Cloud IAM uses roles and permissions to control access to Google Cloud resources.

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.

AWS is a strong choice for the broadest range of cloud services because it has a very large and mature service portfolio covering compute, storage, networking, databases, security, analytics, and many other areas. Its long history in public cloud computing has also resulted in a wide variety of infrastructure and managed services.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure because it integrates closely with Microsoft's ecosystem and provides strong support for Windows, Microsoft services, and enterprise environments. Azure also provides Microsoft Entra ID and Azure RBAC for identity and access management.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud is widely recognized for its strong AI and machine learning capabilities and its close relationship with Kubernetes through Google Kubernetes Engine (GKE). Google originally developed Kubernetes, which contributes to its strong Kubernetes ecosystem.

### 4. What similarities did you observe among the three cloud providers?

All three providers offer equivalent core infrastructure services for computing, storage, networking, and identity management. They also provide scalable resources, security controls, monitoring tools, and services that allow organizations to build and manage cloud-based applications.
