# Laboratory 03 - Multi-Cloud Explorer

This laboratory activity explores three major cloud computing platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

The activity includes research about each cloud provider, a comparison of their services, and recommendations based on different client needs.

The laboratory also includes basic system and network information collected from the Linux environment used during the activity.

## Cloud Platforms

- Amazon Web Services (AWS)
- Microsoft Azure
- Google Cloud Platform (GCP)
