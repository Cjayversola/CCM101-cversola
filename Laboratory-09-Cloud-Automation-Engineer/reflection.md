# Laboratory 09 Reflection

This activity helped me understand why automation is important in cloud computing. When a company manages hundreds of servers, doing tasks manually can take a lot of time and effort. With automation, repeated tasks such as backups and system maintenance can run automatically. This helps save time and reduces the need for manual work.

However, automation also has risks. A small mistake in a script or command can cause serious problems, especially when it affects hundreds or even 1,000 servers. For example, if a script contains an incorrect delete command, it might remove important files from many systems. That is why scripts should be checked and tested before using them on actual servers.

Bash scripting and Docker Compose are both useful tools, but they have different purposes. Bash scripts contain commands that perform tasks in a Linux environment. Docker Compose uses YAML files to define and manage multiple containers and their configurations. In Mission 6, I used Docker Compose to deploy Nextcloud and MariaDB, while in this activity, I used Bash to automate backups.

From Laboratory 1 to Laboratory 9, my understanding of cloud computing has improved. I started by learning the basic concepts of cloud computing and gradually explored infrastructure, cloud platforms, containers, data storage, deployment, security, and automation. I now understand better how different cloud technologies work together.

My favorite cloud engineering role is Cloud Automation Engineer because I find it useful to make repetitive tasks run automatically. This activity allowed me to create a backup script and schedule it using a Cron Job. It also showed me how automation can make cloud operations easier and more efficient.
