# Reflection

In this laboratory activity, I learned about three major cloud computing platforms: AWS, Microsoft Azure, and Google Cloud Platform. I learned that each cloud provider offers different services for computing, storage, networking, databases, and other cloud needs.

I also learned that choosing a cloud provider depends on the requirements of a client or organization. AWS, Azure, and GCP have their own strengths, so it is important to compare their services before making a decision.

This activity helped me understand how cloud computing can be used in real-world situations. It also improved my knowledge of different cloud platforms and their services.
