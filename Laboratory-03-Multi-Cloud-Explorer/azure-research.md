# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides services for computing, storage, networking, databases, security, analytics, and artificial intelligence. Azure is commonly used by businesses and organizations that already use Microsoft technologies.

## Global Infrastructure

Azure has a large global infrastructure made up of regions, availability zones, and data centers. Its regions are distributed around the world so organizations can deploy applications closer to their users and improve availability.

## Cloud Management Console

The Azure Portal is a web-based management console used to create, configure, monitor, and manage Azure resources. Users can manage services such as virtual machines, storage accounts, virtual networks, and Microsoft Entra ID.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide scalable virtual servers that can run Windows or Linux operating systems and different applications.

### 2. Azure Blob Storage

Azure Blob Storage is an object storage service used for storing files, images, videos, backups, and other unstructured data.

### 3. Azure Virtual Network

Azure Virtual Network allows organizations to create private networks in Azure and securely connect cloud resources.

### 4. Microsoft Entra ID

Microsoft Entra ID is an identity and access management service that helps organizations manage users, applications, and access to cloud resources.

## Three Advantages

1. Azure integrates well with Microsoft products and technologies such as Windows Server and Microsoft 365.
2. Azure provides a wide range of services for businesses, including computing, storage, networking, databases, and artificial intelligence.
3. Its global infrastructure allows organizations to deploy applications in different geographic locations.

## Typical Enterprise Use Cases

Azure is commonly used for enterprise applications, Windows Server workloads, Microsoft 365 integration, database systems, web applications, artificial intelligence, data analytics, and hybrid cloud environments.
